# Architecture Decision Records

Ce dossier contient les ADR (Architecture Decision Records) du projet : les décisions
techniques ou d'organisation du code qui méritent d'être tracées et expliquées.

## Format

- Un fichier par décision : `NNNN-titre-court.md` (numéro sur 4 chiffres, incrémental).
- Statut : `Proposé`, `Accepté`, `Rejeté`, `Déprécié`, `Remplacé par ADR-XXXX`.
- Une fois **Accepté**, un ADR n'est plus modifié sur le fond : une nouvelle décision qui
  change la règle se fait via un nouvel ADR qui le remplace.
